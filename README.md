# CodeAlpha Data Analytics Internship Projects

## Project Overview

This repository contains three beginner-level data analytics projects developed using Python as part of the CodeAlpha Data Analytics Internship. These projects demonstrate basic skills in data analysis, data visualization, and sentiment analysis.

The projects use Python libraries to process data, extract meaningful insights, present information visually, and analyze customer opinions.

## Tasks Included

1. Exploratory Data Analysis (EDA)
2. Data Visualization
3. Sentiment Analysis

# Task 2: Exploratory Data Analysis (EDA)

## Objective
To explore a dataset, understand its structure, identify missing values, calculate statistical summaries, and extract useful information.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Description
This project uses a sample student dataset containing names, ages, and marks. Pandas is used to organize and analyze the data. The analysis includes examining the dataset structure, calculating descriptive statistics, checking missing values, calculating average marks, and identifying the student with the highest marks.

A bar chart is also used to represent student marks visually.

## Key Findings
- The dataset contains information about five students.
- The average marks are calculated to understand overall performance.
- Missing values are checked to assess data completeness.
- The student with the highest marks is identified.
- A bar chart makes it easier to compare students' marks.

## Conclusion
Exploratory Data Analysis helps us understand a dataset before performing further analysis. This project demonstrates how Pandas can be used to summarize data, detect missing values, calculate statistics, and identify useful patterns. The findings provide a basic understanding of student performance and demonstrate the importance of data exploration.

# Task 3: Data Visualization

## Objective
To represent data using charts and graphs so that comparisons, patterns, and distributions can be understood easily.

## Tools and Libraries
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Description
This project visualizes the sales of five products: Mobile, Laptop, Tablet, Headphones, and Watch. A sample dataset is created using Pandas, and Matplotlib is used to generate a bar chart and a pie chart.

The bar chart compares the sales values of different products, while the pie chart displays each product's contribution to total sales.

## Key Findings
- Laptops recorded the highest sales of ₹80,000.
- Headphones recorded the lowest sales of ₹20,000.
- Total sales amounted to ₹2,20,000.
- Laptops contributed approximately 36.36% of total sales.
- Headphones contributed approximately 9.09% of total sales.
- The charts make it easier to compare product performance and sales distribution.

## Conclusion
Data visualization transforms numerical information into meaningful graphical representations. This project demonstrates how bar charts and pie charts can be created using Matplotlib to compare sales and understand each product's contribution to total revenue. The results help identify high-performing and low-performing products and demonstrate how visualization can support business analysis and decision-making.

# Task 4: Sentiment Analysis

## Objective
To analyze customer reviews and classify them as positive, negative, or neutral based on their sentiment polarity scores.

## Tools and Libraries
- Python
- TextBlob
- Pandas
- Matplotlib
- Jupyter Notebook

## Description
This project analyzes sample customer reviews about products and services. TextBlob calculates the polarity score of each review, and the program classifies the sentiment based on the score.

Pandas organizes the results into a structured table, and Matplotlib creates a bar chart showing the distribution of sentiment categories.

## Sentiment Classification
- **Positive:** Polarity score greater than 0.
- **Negative:** Polarity score less than 0.
- **Neutral:** Polarity score equal to 0.

Polarity scores range from -1 to +1.

## Key Findings
- Positive reviews express favorable opinions about products or services.
- Negative reviews identify possible customer concerns.
- Neutral classifications indicate reviews without a clearly positive or negative polarity according to the tool.
- A bar chart helps compare the number of reviews in each category.
- Sentiment analysis can help businesses understand customer feedback and identify areas for improvement.

## Conclusion
Sentiment analysis is a useful technique for extracting opinions from textual data. This project demonstrates how TextBlob can classify customer reviews, Pandas can organize the results, and Matplotlib can visualize the sentiment distribution. The analysis provides a basic understanding of customer opinions and demonstrates the potential of natural language processing in customer feedback analysis.

The project uses a small sample dataset, so its findings should not be treated as representative of all customers.
